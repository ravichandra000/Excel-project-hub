# 📊 Amazon Sales Analysis Dashboard | Sapphire IQ Internship

## 📌 Project Overview

This project is part of my **Data Analyst Internship at Sapphire IQ**.

The project focuses on analyzing Amazon sales data using Microsoft Excel 2024 to identify sales trends, understand product category performance, and generate meaningful business insights.

The raw dataset was organized and analyzed using Excel features such as PivotTables, PivotCharts, and data visualization techniques. An interactive dashboard was developed to present the analysis in a clear and understandable format.

## 🎯 Project Objectives

- Analyze Amazon sales data to identify business trends.
- Organize and prepare raw data for analysis.
- Analyze category-wise units sold and sales performance.
- Create PivotTables for meaningful data summarization.
- Develop an interactive Excel dashboard.
- Generate insights to support data-driven business decisions.

## 🔄 Project Workflow

1. **Data Importation:** Imported the Amazon sales dataset into Microsoft Excel.
2. **Data Cleaning:** Reviewed and prepared the dataset for accurate analysis.
3. **Data Preparation:** Organized and formatted the data.
4. **PivotTable Creation:** Created PivotTables to summarize sales information and category-wise units sold.
5. **Data Analysis:** Examined sales performance and product category trends.
6. **Dashboard Development:** Created a dashboard with charts, visualizations, and summary information.
